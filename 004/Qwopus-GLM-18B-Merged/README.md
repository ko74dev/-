# Персональная визитка учителя и технического специалиста

Современный адаптивный шаблон визитки с анимированными градиентами и профессиональной структурой для педагога-IT специалиста.

## 📁 Структура файлов
```
landing/
├── index.html      # Главный файл сайта
├── 0_photo_portret.jpg  # Фото профиля (крупное, квадратное, рекомендуется 400x400px)
├── 1_education_*.jpg    # Фото для раздела педагогическая деятельность (6 шт., 400x300px)
├── 2_it_*.jpg           # Фото для раздела ИТ компетенции (6 шт., 400x300px)
└── README.md             # Этот файл
```

## 🎨 Кастомизация контента

### Основные изменения в `index.html`:

1. **Личные данные (строка 227-229):**
   ```html
   <h1>Алексей Петрович<br>Иванов</h1>
   <p>Квалифицированный педагог...</p>
   ```

2. **Название проекта (строка 13):**
   ```html
   <title>Персональная визитка - Педагог и ИТ-специалист</title>
   ```

3. **Контакты (строки 565-570):**
   ```html
   <a href="mailto:example@yandex.ru" class="contact-link contact-value">
       alexey.ivanov@example.ru
   </a>
   ```
   ```html
   <a href="https://vk.com/alexey.ivanov" target="_blank" rel="noopener noreferrer">
       vk.com/alexey.ivanov
   </a>
   ```

4. **Карты в разделах:**
   - Редактируйте заголовки `<h3>` и описание `<p>` в каждой карточке
   - Иконки (эмодзи в `.card-icon`) можно заменить на SVG или изображения

5. **Фото в галереях:**
   - Путь к фото уже указан в `src`, замените на свои файлы
   - Если фото отсутствуют, используйте placeholder-ы (автоматически подгружаются)

## 📱 Адаптивность

Сайт полностью адаптирован под все типы устройств:
- **Desktop:** 3 колонки в сетке карточек
- **Tablet (≤768px):** 2 колонки в сетке карточек  
- **Mobile (≤480px):** 1 колонка в сетке карточек

## 🚀 Публикация в интернете

### Вариант 1: GitHub Pages (бесплатно)
1. Зарегистрируйтесь на GitHub
2. Создайте репозиторий с именем `username.github.io`
3. Загрузите файлы в корневую директорию
4. Сайт автоматически опубликуется

### Вариант 2: Тинькофф Блоки
1. Зарегистрируйтесь на https://blocks.io
2. Создайте новый проект
3. Перетащите `index.html` и все изображения
4. Получите готовую ссылку

### Вариант 3: Netlify Drop
1. Зарегистрируйтесь на https://app.netlify.com/drop
2. Перетащите всю папку `landing` в окно загрузки
3. Сайт опубликуется автоматически

### Вариант 4: Яндекс.Диск (просто и быстро)
1. Создайте новую папку на Я.Диске
2. Перетащите туда все файлы
3. Нажмите «Создать сайт» (если есть доступ)
4. Или просто отправьте ссылку друзьям
